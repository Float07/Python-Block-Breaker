# Python Block Breaker

Made with Pyxel

## Prerequisites

- Python 3.8+

## Setup

Create a virtual environment and install the dependencies (just Pyxel) into it:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

Activate the virtual environment, then run the game's entry point:

```sh
source .venv/bin/activate
python3 src/main.py
```
